## 5. The check (B) — EXECUTION, Thurgood's, in its own PR

- **Path**: `scripts/completion-claims/edit-kind-pointers.ts`, test `scripts/completion-claims/__tests__/edit-kind-pointers.test.ts`. Both are inside Thurgood's standing scope (`scripts/completion-claims/**`), so no write-scope change is owed. Root `npm test` runs the test (its roots include `scripts/completion-claims`).
- **Input**: `--pr <n>`. It reads `gh pr view <n> --json body,baseRefOid,headRefOid,mergeCommit` (the body, never the squash message), and the diff from the merge base to the merge commit, or to the head while the PR is open.
- **Decision**, per `**Edit kind**:` line whose kind is LAW or CORRECTION:
  - The file's added lines are read, limited to `L<a>–<b>` when the line gives a range.
  - **Bound path**: at least one added line matches `/\*\((amended|corrected|added) \d{4}-\d{2}-\d{2}/i`. For `governance/classification-map.md`, an added line matches `/^\s*- \{ date: \d{4}-\d{2}-\d{2}/` instead.
  - **Exempt path** (`canonical/agents/**`): no added line matches the pointer pattern.
  - EXECUTION lines are listed and not checked. An EXECUTION edit's pointer, where one is owed, is the claims-pass read's, as before.
- **Output**:
  - one line per declared file: `<path>\t<KIND>\t<ok | pointer-missing | pointer-on-exempt | unlisted-path>`;
  - then the counts.
  - It exits 0 always; a failure prints one `edit-kind-pointers: unavailable (…) — continue` line.
- **Status**: a finding, never a gate. It is wired into no required check and adds no `EXPECTED_CONTEXTS` entry. Stacy runs it as a limb of her governance-edit-kind read, and a non-`ok` line is a finding on the authoring agent.
- **Register**: the build PR fills the row's `checks` and moves `check_state` from `proposed` per the register's procedure. It writes `census`: either a census mode over a named PR list, or `census: none — <why>` in the owner's words. The PR-body corpus sits outside git, the question open at `.kiro/issues/2026-10-27-census-corpus-outside-git-question.md`.
- **Its gap, stated**: a governance edit with a missing or wrong Edit-kind line escapes the check. Stacy's edit-kind read already covers that half.
- **Falsification cases** (Stacy specifies them, § 8 question S2). The minimum:
  - #535's PTG line (bound, pointer added → `ok`);
  - #541's `stacy.md` line (exempt after this ballot, pointer added → `pointer-on-exempt`);
  - a CORRECTION on a bound path without a pointer → `pointer-missing`;
  - a register CORRECTION with a history line → `ok`.
