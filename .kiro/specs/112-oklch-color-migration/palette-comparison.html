Shared Lightness Scale Used (proposed)

StepLightnessIntended Use
1000.95Backgrounds, tints, very light fills
2000.82Subtle fills, secondary surfaces
3000.70Primary decorative, medium fills
4000.55Strong fills, interactive elements
5000.40Dark accents, text on light backgrounds

Chroma values in the right palette are approximate — tuned per-family to stay within sRGB gamut at each lightness level. The exact values would be refined during implementation with Ada's gamut validation.
