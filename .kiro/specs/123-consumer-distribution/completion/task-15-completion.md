## Lessons (Standards implications)

- **The instrument-existence block worked.** 40 rows were written before code. Its first `## Found later` entry (the shared branch of `emitSpans`, found at 15.1) became the #240 grant amendment before 15.3 needed it. The second (the M1 event counter) was self-reported at 15.5.
- **Mutations are restored from a saved copy, never with `git checkout --` on a file that holds uncommitted work.** At 15.3 a `git checkout -- adapters/cc.ts` wiped uncommitted edits. They were restored from `/tmp/cc.bak`, and every mutation since has been restored from a saved copy and verified with `cmp`.
- **Parallel seats need per-seat scratch subdirectories.** Two seats' helper scripts overwrote each other in the shared session scratchpad. Nothing wrong was written, because the chains failed closed. The drafting aids now resolve the repo root from `process.cwd()`, so a side worktree sweeps itself.
- **Pack with scripts** (Ada): `npm pack --ignore-scripts` tests workspace leftovers, not the published file set. That is how the snapshot refusals found a mix of real and apparent staleness.
- **Classifier learning, in two rulings:**
