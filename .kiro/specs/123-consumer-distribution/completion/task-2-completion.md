## Adaptations and carried items

1. **The scaffolded `tsconfig.test.json`'s `moduleResolution`/`module` changed from `'bundler'`/`'commonjs'` to `'node16'`/`'node16'`** — a genuine pre-existing defect (present before Task 2, inherited verbatim), surfaced by building Task 2.5's real `tsc --noEmit` arbiter for the first time: `moduleResolution: 'bundler'` requires `module` to be `'preserve'` or `>= 'es2015'` under TypeScript 5.9 (TS5095), incompatible with `'commonjs'`. `module: 'node16'` was verified to still emit CommonJS for a package with no `"type": "module"` (load-bearing: `src/testing/jest-preset.ts` passes this SAME tsconfig to `ts-jest`'s runtime transform, so an ESM `module` setting would have broken actual test execution for every scaffolded consumer) while resolving `@3fn/core/*` subpaths through the real `package.json` `exports` map. Recorded in `.kiro/specs/123-consumer-distribution/completion/task-2-3-completion.md` § "Application-time adaptations" #1 and `task-2-5-completion.md`.
