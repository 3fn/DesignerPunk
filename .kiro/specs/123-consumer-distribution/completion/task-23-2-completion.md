## The declared-list assertion (my call, as handed to me)

The list is already declared in the code, so the assertion adds no second list, and a third declared doc would be covered by adding its name in one place.
**The wording conflict to resolve**: the ruling, `tasks.md` Task 23 criterion 3 and B-U4 § 3 call the two docs "banded and unguarded". My assertion guards their **presence** (not the predicate's coverage of them). If "unguarded" was meant strictly, delete that one `describe` block (nothing else depends on it) and the two docs go back to unguarded. If it meant "outside the predicate's guard", the three texts should say so.
