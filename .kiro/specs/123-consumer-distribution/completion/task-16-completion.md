## Application-time adaptations

1. **Survivor rows in the lane** (16.1): `emitConsumer` renders the derived text with every surviving unit `retained`, since derive() already pruned the rest. Parity is the evidence the two paths agree; a future `emitSpans` behaviour that depends on a disposition beyond survive-or-not would diverge here, and parity is what would catch it.
2. **The prepack derive restates `generateConsumerRendering`'s step 1**, because `generate.ts` can neither ship in the bundle nor be edited (ruling 5). Parity's first case pins it byte-for-byte to `_canonical/`, and three restated constants are pinned equal.
3. **`emitConsumer` returns `keys: []`.** MCP config and approval keys stay with `src/cli/shared/mcpConfig/{cc,kiro}.ts`; `init` and `attach` compose them.
4. **`package-mode` is attachable**, like `born` (16.2; confirmed at 16.5 — DD23 made it a posture). `--skip-agents` = no agent files, no `attachedTargets` entry, MCP still wired (16.3; confirmed at 16.5).

6. **Region edited inside** applies only with `--apply` or `--overwrite CLAUDE.md#managed`, never with the TTY batch confirmation alone.
7. **The cohort test synthesizes the copied tree** (the fixture holds hashes, not bytes, as its README directs). "Unmodified" for a legacy copy is judged against the recorded hash; for a Spec 111 entry that is the first-sync baseline (the same bootstrap caveat C7 step 2 names), a recorded residual.

## Lessons (Standards implications)

- **A subtask that changes what ships must run the lane that installs it.** Two red windows (Consumer Guard, the relocation gate) came from 16.3 changing the install shape without running `npm run test:consumer` or the `mcp-server` suite, both outside the root `npm test`. The instruments block listed the lane as 16.6's instrument, which read as "only 16.6 runs it". A block row whose instrument is a lane should name every subtask that can break it, not just the one that cites it.
- **A local build can hide a CI build failure** when a gitignored artifact (`mcp-server/dist`) exists only locally. The bundle test now builds with it moved aside; the same "move the artifact aside" step belongs in any test that builds a bundle.
- **Confirming a Sonnet seat's flagged calls is where defects surface.** Both 16.2 defects were found because 16.2 flagged its region wiring for confirmation. Flags with a stated alternative are worth the PRIMARY's time.
- **Re-run bites at the parent, don't only cite them.** Two counts had moved; one is untraced. Neither changed a verdict, but a cited count alone would have hidden the drift.
