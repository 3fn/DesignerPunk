## Design Outline Feedback

### Context for Reviewers
- This integrates Impeccable (25k star Apache 2.0 project) as a design critique capability within DesignerPunk's developer experience
- Framed as a workflow-tier/system-tier concern, not product-tier — it ships with `@designerpunk/core`
- Phased approach: skill integration first (zero cost), then system-aware filtering, then full MCP/CLI integration
- No new agent — capability added to existing agents (primarily Leonardo and platform agents)
- Web-focused initially; cross-platform critique is a future concern
- Token system overrides Impeccable's taste rules (system wins over generic opinions)
