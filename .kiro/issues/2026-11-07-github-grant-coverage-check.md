## The owed act

A check that each `.github/**` path in a PR's diff is covered by an activated issue-row grant record or a charter standing-scope clause. It is decidable over git and the issue records, and it emits before any red is proposed. Stacy specifies its falsification fixtures (Q5).

## What it does not close

The added-line half that Stacy R1 names: an added `continue-on-error: true` passes a path check. Path coverage says who may write a file, not what was written into it. ARMING's read of the diff stays the only reader of that half.

## Grant paths

None. Nothing is written under this record until it is amended with a list in a merged PR (rule 10).
